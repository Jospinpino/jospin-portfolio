# Projets Python

Quatre projets Python indépendants, chacun avec ses propres tests unitaires (`python -m unittest`, tous passent) et son README détaillé.

- **[taskflow-api](taskflow-api/)** : API REST Flask pour la gestion de tâches (SQLite, routes CRUD, 12 tests)
- **[file-organizer-cli](file-organizer-cli/)** : outil CLI qui range automatiquement des fichiers par type, avec mode aperçu (7 tests)
- **[password-strength-checker](password-strength-checker/)** : vérificateur de force de mot de passe, 100% hors ligne (8 tests)
- **[expense-analyzer](expense-analyzer/)** : analyse de dépenses à partir d'un CSV, avec graphiques (6 tests)

Chaque dossier peut être utilisé indépendamment, avec ses propres dépendances listées dans `requirements.txt` quand nécessaire.
